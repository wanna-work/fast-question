# FAST START: анкета-бриф

**Статус: не проверено.** Код не запускался в браузере и не подключён к Google. Публиковать можно только после шагов 1–6 и тестовой отправки.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Анкета (5 этапов), генерация брифа и промпта, отправка |
| `Code.gs` | Приём анкеты в Google Apps Script и письмо владельцу |
| `policy.html` | Шаблон политики обработки персональных данных |
| `terms.html` | Шаблон условий заказа |
| `README.md` | Эта инструкция |

## Настройка

1. **Apps Script.** Откройте script.google.com → «Новый проект». Удалите всё, вставьте содержимое `Code.gs`.
2. **Почта.** В первой строке настроек замените `OWNER_EMAIL` на свою почту.
3. **Публикация сервера.** «Развёртывание» → «Новое развёртывание» → тип «Веб-приложение». Выполнять от имени: «Я». Доступ: «Все». Разрешите доступ к почте. Скопируйте адрес вида `https://script.google.com/macros/s/.../exec`.
4. **Адрес в анкете.** В `index.html` найдите `ENDPOINT:""` и вставьте адрес между кавычками.
5. **Документы.** Заполните все `[ЗАПОЛНИТЬ]` в `policy.html` и `terms.html`. Проверьте их с юристом.
6. **Хостинг.** Загрузите `index.html`, `policy.html`, `terms.html` на статический хостинг (например, Cloudflare Pages или Netlify). `Code.gs` на хостинг не нужен.

После любого изменения `Code.gs` нужно сделать новое развёртывание, иначе работает старая версия.

## Почему не GitHub Pages

- Репозиторий публичный: любой увидит код и адрес Apps Script, и сможет слать на него запросы. Защита есть (ловушка для ботов, лимит размера, защита от дублей), но она базовая.
- Главный риск не в хостинге страницы, а в том, куда уходят данные: Google Apps Script и почта. Если клиенты из России, нужно проверить требования 152-ФЗ о персональных данных (в том числе о месте хранения и уведомлении оператора) и указать сервисы в политике. Это вопрос к юристу.
- Статический хостинг Cloudflare Pages или Netlify подходит для самой страницы лучше: можно закрыть код репозитория и настроить заголовки.

## Проверка перед запуском

- [ ] На телефоне и компьютере анкета проходится от начала до конца.
- [ ] Кнопки «Назад» и «Дальше» не теряют ответы; после перезагрузки страницы ответы на месте.
- [ ] Условия: «Другое» открывает поле; «Пока нечего показать» убирает проекты; можно добавить до трёх проектов.
- [ ] Оба чекбокса согласий пустые при открытии и без них отправка невозможна.
- [ ] Некорректная ссылка в проекте даёт ошибку.
- [ ] Тестовая отправка: письмо пришло, тема `FAST START — новая анкета: [имя]`, в письме бриф и промпт.
- [ ] Повторное нажатие «Отправить» не создаёт второе письмо.
- [ ] Если отключить интернет и нажать «Отправить», успех не показывается, ответы остаются.
- [ ] «Начать заново» спрашивает подтверждение и стирает ответы.
- [ ] В коде нет паролей и ключей. Адрес Apps Script виден всем, это нормально.

## Ограничения

- У бесплатных аккаунтов Google есть суточный лимит писем.
- Защита от повторов работает до 6 часов (ограничение кэша Google).
- Загрузка файлов не реализована: клиент даёт ссылки.
